Line following

Robot doesn't follow the line?

Go through these in order:
  1. Sensors: move the robot by hand across the line. The bars in Line sensors should go dark one after another, and the blue dot should follow the line. If nothing changes, click Calibrate on the Drive tab with the robot on the line.
  2. Wheel direction: hold Left wheel below. The left wheel must turn forward. If the other wheel turns, tick Swap motors. If it turns backward, tick Invert left. Do the same for the right wheel.
  3. Steering: start a run. If the robot turns away from the line right away, tick Invert steering.
  4. Speed / PID: if it wobbles and loses the line, lower the base speed or P on the Tuning tab.
